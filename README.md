#  Projet de Prédiction Météorologique
Un système de prédiction météo utilisant des techniques d'apprentissage automatique pour prédire la température et l'humidité.


## Architecture

Ce projet est structuré en plusieurs composants :
- Traitement des données météo
- Entraînement de modèles ML
- API de prédictions
- Système de stockage des données et modèles


### Prérequis
- Python 3.10+
- Docker et Docker Compose (optionnel)
